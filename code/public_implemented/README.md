 # TLS Fingerprint Implementations

The JA3 and JA3S fingerprint scripts in this directory are taken from the
[Salesforce JA3 repository](https://github.com/salesforce/ja3). The JA4
fingerprint scripts are taken from the [FoxIO JA4 repository](https://github.com/FoxIO-LLC/ja4).

The known fingerprint database was collected by running these fingerprinting
scripts against the corresponding network traffic samples. The database and
the generated fingerprint files are provided for reference and testing.
